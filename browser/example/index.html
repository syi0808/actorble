Actorble browser

Examples

01 GitHub explorer Search a repository, open Issues, and inspect an issue with visible click-focus input. 02 Form filling Fill a realistic request form, toggle a checkbox, and submit it. 03 Web search Type a search query, load results, and open a result preview. 04 Appointment scheduler Search for a patient, draft a visit, drag it onto the calendar, and confirm it. 05 Selection and pointer sequence Select text across surfaces, distinguish click and drag, and replay a closed pointer sequence. 06 Research clipping Select a source quote, save it as a clipping, add a note, and publish the result. 07 Nested reveal lab Reveal a nested target, observe visual stability, interrupt timed motion, and recover.
